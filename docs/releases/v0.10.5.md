# Needle 0.10.5

Failed saves now retain the approved audio source, recording metadata, artwork, output settings, and Spotify delivery choice. Choose **Retry** in Activity to repeat an eligible failed save using that approval.

Needle keeps a durable copy of approved artwork, so a retry uses the same cover even if its original link changes or a custom image is moved. Saves with an uncertain file outcome require Library review before another download. Older Activity entries without a retained approval still need a new review.

## Installation

Download **Needle-0.10.5.dmg** for **Apple Silicon Macs, macOS 15 Sequoia or later**. Open the disk image and drag Needle to Applications. The app bundles the CLI and audio tools.

The app is unsigned by an Apple Developer ID and is not notarized. If macOS blocks first launch, use **System Settings → Privacy & Security → Open Anyway**. Keep Gatekeeper enabled.
