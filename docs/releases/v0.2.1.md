# Needle 0.2.1 preview

Preserves explicit remix titles when metadata resolves the original album track, without copying the original album or track number.

Also fixes a packaged-app launch failure: Needle now finds the Sparkle framework inside its own app bundle after installation in Applications.

This is a new source version. The existing 0.2.0 source tag has not been moved or replaced.

The canonical Whethan SoundCloud recording was checked in the installed app: source quality showed 160 kbps with approximately 2 million provider-reported plays, and its in-app preview played with progress. These source values can change. The restarted save retained “Nissan Altima (Whethan Remix)” with no original-album tags. Its exact 2:10 local recording was confirmed in the Needle Spotify playlist and played there.

For Apple Silicon Macs. The planned shared build targets macOS 15 or later, subject to each artifact's bundled-tool requirements and verification. The current local review build requires macOS 27 because of its FFmpeg build. See [Getting started](https://github.com/icebli/needle/blob/main/docs/GETTING_STARTED.md).

This unsigned draft is for review and is not yet a signed, notarized installer ready for friends. Production publication requires Developer ID signing, Apple notarization, compatibility validation, and verified corresponding sources and notices for all bundled third-party tools. Sparkle update checks remain disabled in unsigned previews; no production update is available yet.

Spotify Local Files works without the optional Needle Spicetify companion. Without that companion, turn off **Add to Needle in Spotify after saving** before choosing **Save recording**.
