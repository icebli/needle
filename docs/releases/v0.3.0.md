# Needle 0.3.0

## What's new

- **Review Queue:** paste multiple links or artist/title lines, review each recording, and approve downloads individually. Two downloads can run in the background while you keep reviewing. Your queue survives restarting Needle.
- **Smarter previews:** scrub through the full recording, skip long intros, jump ten seconds, and compare candidates at the same timestamp.
- **Library Repair:** add or replace embedded artwork, fix artist/title/album tags, or review metadata suggestions without downloading the audio again. Needle creates an original-file backup before each repair.
- **Guides in every tab:** click **?** for instructions and troubleshooting for Add Music, Review Queue, Activity, and Library.
- Clearer candidate cards, artwork refreshes, and more reliable cancellation.

## Install

For **Apple Silicon Macs (M1 or newer), macOS 15 Sequoia or later**. Download **Needle-0.3.0.dmg**, open it, and drag Needle to Applications.

This app is unsigned and not notarized. If macOS blocks launch, choose **System Settings → Privacy & Security → Open Anyway**. See [Getting started](https://github.com/icebli/needle/blob/main/docs/GETTING_STARTED.md). The installer includes its audio tools; no Homebrew, Rust, Python, or Terminal setup is needed.

## Upgrade

Existing users can choose **Needle → Check for Updates…**. Updates are authenticated with Needle's update-signing key. macOS may require Open Anyway again for an unsigned update. Manual replacement using the DMG is also supported. Saved music, history, settings, and the review queue stay on your computer.

## Spotify and limitations

Spotify Local Files works without [Spicetify](https://spicetify.app/). Automatic playlist delivery requires Spicetify and the optional Needle companion. Leave delivery off unless both are installed; Review Queue starts with delivery off. Spotify may take time to index new files or refresh repaired tags/artwork. A saved file and a confirmed playlist addition are shown separately.

Full-track preview preparation can take time. Missing source bitrate or view counts remain Unknown. Metadata suggestions may be unavailable for obscure recordings; original-source artwork and manual edits remain available. Interrupted queue downloads require review before retrying.

The queue, preview, and repair flows were tested in the installed app using Doechii — Nissan Altima (Whethan Remix). Repairs preserved decoded audio and all 57 pre-existing test-library files. The installer is built on an Apple Silicon macOS 15 runner; testing on a separate clean macOS 15 machine remains outstanding.

Download **needle-companion.zip** for Chrome, Firefox, or Zen and follow the [companion setup guide](https://github.com/icebli/needle/blob/main/docs/browser-extension.md).
