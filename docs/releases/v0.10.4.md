# Needle 0.10.4

Failed saves now show their reason and recovery guidance directly in Activity. Full diagnostic output stays available under Technical details. Spotify delivery failures distinguish files already saved locally from saves that did not finish.

Needle now accepts source artwork served as WebP, including thumbnail links ending in `.jpg`. It converts the approved image to JPEG for embedding while preserving the chosen artwork, audio source, and recording metadata. Invalid images still fail with a visible explanation.

## Installation

Download **Needle-0.10.4.dmg** for **Apple Silicon Macs, macOS 15 Sequoia or later**. Open the disk image and drag Needle to Applications. The app bundles the CLI and audio tools.

The app is unsigned by an Apple Developer ID and is not notarized. If macOS blocks first launch, use **System Settings → Privacy & Security → Open Anyway**. Keep Gatekeeper enabled.
