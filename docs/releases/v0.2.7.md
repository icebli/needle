# Needle 0.2.7

- New record-player logo and sharper app icon.
- Preview recordings before saving, with source bitrate and play/view counts.
- Activity shows saved files and the Spotify playlist destination separately.
- Advanced Settings and the CLI remain available.

## Install

For Apple Silicon Macs. Download **Needle-0.2.7.dmg**, open it, and drag Needle to Applications. This app is unsigned: on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS asks. See [Getting started](https://github.com/icebli/needle/blob/main/docs/GETTING_STARTED.md).

## Updates and Spotify

Choose **Needle → Check for Updates…** for newer versions. Unsigned updates may require macOS approval again. Your saved music stays in your Music/needle folder.

Spotify Local Files works without Spicetify. Automatic playlist delivery requires the optional Needle companion; leave that option off unless the companion is installed.
