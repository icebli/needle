# Needle 0.2.5 — Unsigned friend preview

This preview is intended for invited friends on Apple Silicon Macs. It is unsigned, so macOS may require a one-time **Open Anyway** approval in **System Settings → Privacy & Security**. Do not disable Gatekeeper or remove quarantine attributes.

## Included

- Friend-facing install instructions and a safer manual update path.
- Clear explanation of Sparkle's Ed25519 update verification versus Apple's Developer ID and notarization.
- The polished desktop Activity presentation, while retaining advanced Settings and the full CLI.

## Update behavior

The preview keeps automatic update checks disabled until an unsigned Sparkle update has been tested end to end. Sparkle can verify update signatures without notarization, but macOS may still require manual approval after an updated unsigned app is installed. Download updates only from the official [GitHub releases page](https://github.com/icebli/needle/releases).

## Platform

Apple Silicon only. Check the release assets and manifest for the exact minimum macOS version.
