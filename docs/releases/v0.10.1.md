# Needle 0.10.1

Needle now fills missing covers for existing bookmarks and saved recordings. Artwork matching keeps the recording, featured artists, and release identity together. It tries additional eligible editions when a cover is missing and supports original mixtapes. Upload presentation labels and production credits no longer block otherwise verified matches.

Conflicting source details and unreviewed album variants stay unresolved rather than receiving a guessed cover. The app distinguishes metadata review, missing source evidence, catalog misses, and lookup failures. Previous misses are checked again after this upgrade. Explicit tag repairs retain a reviewed snapshot and backups for future artwork checks.

Add Music accepts a source link on its own. Detected artist and song details remain editable before source approval. Discover loads more artists and supports larger selections.

When you repair metadata on a file previously delivered to Spotify, Needle queues an update and waits for Spotify to index the corrected tags. It confirms the replacement before removing the old playlist row. Ambiguous rows remain unchanged. Spotify can retain cached metadata or artwork; a queued update does not guarantee an immediate visual refresh.

## Installation

Download **Needle-0.10.1.dmg** for **Apple Silicon Macs, macOS 15 Sequoia or later**. Open the disk image and drag Needle to Applications. The app bundles the CLI and audio tools. The companion archive supports browser and Spotify integrations.

The app is unsigned by an Apple Developer ID and is not notarized. If macOS blocks first launch, use **System Settings → Privacy & Security → Open Anyway**. Keep Gatekeeper enabled.

## Verification and limits

Rust, Swift desktop, JavaScript integration, packaging, and release checks passed locally. Missing-cover lookup and metadata repair were tested against saved audio, with unchanged audio stream hashes. The installed app showed the repaired covers. Release CI separately checks the packaged tools without Homebrew on PATH and validates corresponding-source materials.

This is strict metadata and source matching, not audio fingerprint verification. Some recordings have no verified catalog cover, and legacy metadata conflicts still require review. A separate clean macOS 15 machine has not been tested.
