# Needle 0.2.0 preview

A native macOS app for finding the right recording, previewing it, and saving a tagged file for your local music collection.

- Review candidates with real artwork, available source bitrate and view counts.
- Listen to a 30-second audio preview before saving.
- See recording mismatches and scoring explanations before choosing a source.
- Track downloads and see the Spotify playlist name and link when delivery succeeds.
- Keep advanced options and the full CLI available.
- Includes Sparkle update support and a Check for Updates menu item for configured release builds. Unsigned previews keep update checks disabled.
- New drag-to-Applications installer packaging bundles the audio tools.

For Apple Silicon Macs. The planned shared build targets macOS 15 or later; each artifact's actual minimum version is derived from its bundled tools. The local review build requires macOS 27 because of its FFmpeg build. See [Getting started](https://github.com/icebli/needle/blob/main/docs/GETTING_STARTED.md).

This draft is for packaging review. It is not yet a signed, notarized release for friends. Publishing requires Developer ID signing, Apple notarization, and verified corresponding sources and notices for every bundled third-party tool. The update feed has no production release yet; update publication additionally requires verified Sparkle update signatures. Spotify playlist automation requires the optional Spicetify companion; Spotify Local Files works without it. Without the companion, turn off **Add to Needle in Spotify after saving** before saving a recording.
