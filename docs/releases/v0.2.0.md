# Needle 0.2.0 — Preview

- Native Mac app with Add Music, Activity, and Library.
- Candidate artwork, source bitrate, view counts, and recording identity warnings.
- In-app audio previews before saving.
- Named Spotify playlist destinations and delivery status.
- Advanced Settings and CLI commands.

This preview is unsigned and intended for Apple Silicon Macs. Check the download’s minimum macOS version before installing. Follow [Getting started](https://github.com/icebli/needle/blob/main/docs/GETTING_STARTED.md) for installation, macOS **Open Anyway** approval, and updates.

Spotify Local Files works without the optional companion. Turn off **Add to [playlist] in Spotify after saving** unless you have installed that companion.
