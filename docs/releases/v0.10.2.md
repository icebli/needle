# Needle 0.10.2

Needle matches release artwork even when an upload and the catalog use different version labels. Artist, title, duration, and version evidence determine whether a cover is compatible. For example, MAAN! Weedmix can use the 28 Grams cover without changing the recording's tags.

Existing bookmarks and saved recordings use the same matching. Previous misses become eligible again after this upgrade. If no compatible catalog cover is found, Needle uses artwork from the exact selected source when available. Existing covers and explicitly cleared artwork remain unchanged. Saved-file fills create a backup and preserve the audio and recording metadata.

Metadata review selects source artwork automatically when no release cover is available. You can still choose a different image or clear it. Discover also requires corroborating artist evidence and distinguishes failed Spotify lookups from recordings confirmed absent.

## Installation

Download **Needle-0.10.2.dmg** for **Apple Silicon Macs, macOS 15 Sequoia or later**. Open the disk image and drag Needle to Applications. The app bundles the CLI and audio tools. The companion archive supports browser and Spotify integrations.

The app is unsigned by an Apple Developer ID and is not notarized. If macOS blocks first launch, use **System Settings → Privacy & Security → Open Anyway**. Keep Gatekeeper enabled.

## Limits

Artwork matching uses catalog and source evidence, not audio fingerprints. Conflicting recording identities remain unresolved. Temporary provider failures are retried. A separate clean macOS 15 machine has not been tested.
