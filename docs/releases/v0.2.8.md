# Needle 0.2.8

- New record-player logo and sharper app icon.
- Preview recordings before saving, with source bitrate and play/view counts.
- Activity shows saved files and the Spotify playlist destination separately.
- Advanced Settings and the CLI remain available.
- Chrome companion bundle with a setup command that uses the installed Mac app; Firefox and Zen are included.
- Authenticated updates verified through download, installation, and relaunch.

## Install

For **Apple Silicon Macs (M1 or newer) running macOS 15 Sequoia or later**. Download **Needle-0.2.8.dmg**, open it, and drag Needle to Applications. This app is unsigned: on first launch, use **System Settings → Privacy & Security → Open Anyway** if macOS asks. See [Getting started](https://github.com/icebli/needle/blob/main/docs/GETTING_STARTED.md).

## Updates and Spotify

Choose **Needle → Check for Updates…** for newer versions. Unsigned updates may require macOS approval again. Your saved music stays in your Music/needle folder.

Spotify Local Files works without [Spicetify](https://spicetify.app/). Automatic playlist delivery requires Spicetify and the optional Needle companion; leave that option off unless both are installed. Download **needle-companion.zip** from Assets and follow the [companion setup guide](https://github.com/icebli/needle/blob/main/docs/browser-extension.md). Chrome currently uses Developer mode / Load unpacked; Firefox and Zen use a temporary unsigned add-on.
